ccjuice▌

How much juice is left in your Claude Code tank? Session & weekly limits, right next to your clock.

Install for macOS

Features

Every quota, one glance

Session, weekly & Opus limits with reset countdowns.

Knows your pace

"At this pace, session empty in ~1h 05m."

Warns before zero

Alerts at your threshold, and when the session resets.

Install

# Homebrew
brew tap araltiparmak/ccjuice https://github.com/araltiparmak/ccjuice
brew install --HEAD araltiparmak/ccjuice/ccjuice
# or build from source
git clone https://github.com/araltiparmak/ccjuice.git
cd ccjuice && ./build.sh && open CCJuice.app

macOS 12+, Xcode Command Line Tools, and Claude Code logged in. On first launch choose Always Allow for Keychain access.

Security & privacy

CCJuice reads the OAuth token Claude Code already stores in your macOS Keychain and asks api.anthropic.com for your utilization. That's the only network call it makes.

No analytics, no tracking, no third-party servers. A few hundred lines of readable Swift — verify it yourself.
